# Muhammad Ashir — Portfolio

A responsive, dark technical portfolio inspired by the supplied `profolio.mp4` reference and personalized with Muhammad Ashir's verified public profile, experience, education, and projects.

## Live site

GitHub Pages deployment: **https://muhammadashir0.github.io/Portfolio/**

The production site is included in `docs/` for GitHub Pages. In repository settings, choose **Deploy from a branch**, select `arena/04d42ef3-portfolio`, and choose the `/docs` folder.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Included

- Responsive React + Vite single-page portfolio
- Scroll-triggered multi-agent construction tour (never scrolls the page automatically)
- Interactive MandatePay architecture explorer
- Real project dashboard captures and verified impact summaries
- Filterable matrix covering eight AI, FinTech, data, speech/NLP, enterprise, and web projects
- Four verifiable Claude/AI certifications with public Skilljar links
- Professional experience and education timeline
- Downloadable, user-supplied CV at `public/muhammad-ashir-cv.pdf`
- GitHub, LinkedIn, email, and data-portfolio links
- Accessible mobile navigation, reduced-motion support, and semantic sections
